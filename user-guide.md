# QPort — User Guide / Hướng dẫn sử dụng

QPort now ships with complete start-to-finish documentation in both supported operational UI languages.

## English

Read:

[`docs/USER_GUIDE_EN.md`](docs/USER_GUIDE_EN.md)

The guide covers installation, first portfolio import, market-data sync, ledger event types, NAV/P&L verification, TWR/XIRR, risk, strategic reference weights, EOD routine, backup/recovery and troubleshooting.

## Tiếng Việt

Đọc:

[`docs/USER_GUIDE_VI.md`](docs/USER_GUIDE_VI.md)

Tài liệu bao gồm cài đặt từ đầu, nhập danh mục thật, đồng bộ giá, các loại ledger event, kiểm tra NAV/P&L, TWR/XIRR, risk, strategic reference weights, routine cuối ngày, backup/restore và troubleshooting.

## In-app guide

After starting QPort, open:

```text
http://127.0.0.1:8080/guide
```

Use the `EN` / `VI` switch in the top navigation. QPort stores the selected language in the `qport_lang` browser cookie.

## Product boundary

These guides describe the **Buy & Hold operational product**. Legacy optimizer/backtest tooling remains isolated inside Research Lab and may retain English-only research labels.
