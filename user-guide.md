# QPort — User Guide / Hướng dẫn sử dụng

QPort provides complete start-to-finish documentation in both supported languages.

## English

[`docs/USER_GUIDE_EN.md`](docs/USER_GUIDE_EN.md)

Covers installation, portfolio migration, available cash, market sync, accounting
reconciliation, ledger events, historical snapshot rebuild, Performance, Drawdown,
Risk, Portfolio Health, optional target-weight guidance, daily operation, backup
and troubleshooting.

## Tiếng Việt

[`docs/USER_GUIDE_VI.md`](docs/USER_GUIDE_VI.md)

Bao gồm cài đặt, chuyển danh mục hiện có, tiền mặt khả dụng, đồng bộ dữ liệu, đối
chiếu accounting, ledger events, dựng lại snapshot lịch sử, Hiệu suất, Drawdown,
Rủi ro, Sức khỏe danh mục, tỷ trọng tham chiếu tùy chọn, routine hằng ngày, backup
và troubleshooting.

## In-app guide

After starting QPort:

```text
http://127.0.0.1:8080/guide
```

Use the `EN / VI` switch in the top navigation. Language preference is persisted
in the `qport_lang` browser cookie.
