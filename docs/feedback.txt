## 1. P0 cash-flow basis: ✅ PASS

Đây là sửa quan trọng nhất.

DGC giờ ghi rõ:

```text
cashflow_basis          = NET_INCOME_OWNER_EARNINGS
discount_rate_basis     = COST_OF_EQUITY
result_type             = EQUITY_VALUE
debt_adjustment_policy  = NO_NET_DEBT_ADJUSTMENT
```

và `equity_value` không còn bị trừ net debt lần thứ hai. 

Tôi parse toàn bộ scenario trong 68 reports và thấy mapping nhất quán:

```text
NET_INCOME_OWNER_EARNINGS
→ COST_OF_EQUITY
→ EQUITY_VALUE
→ NO_NET_DEBT_ADJUSTMENT

FCFF
→ WACC
→ ENTERPRISE_VALUE
→ SUBTRACT_NET_DEBT

RESIDUAL_INCOME
→ COST_OF_EQUITY
→ EQUITY_VALUE
→ NO_NET_DEBT_ADJUSTMENT
```

Phía FCFF cũng đúng. ACV hiện dùng:

```text
FCFF
WACC
ENTERPRISE_VALUE
SUBTRACT_NET_DEBT
```



**Về arithmetic, lỗi double-count debt trước đây coi như đã đóng.**

Một cleanup nhỏ còn lại: với OE-equity DCF, field vẫn tên `enterprise_value` dù `result_type=EQUITY_VALUE` và nó bằng chính equity value. Nên đổi field thành `present_value` hoặc `equity_cashflow_value` để consumer khác không hiểu nhầm.

# 8. Một vấn đề semantic vẫn còn: `MODEL_INCOMPLETE` nhưng vẫn giữ Base IV

Ví dụ DGC:

```text
model_status = MODEL_INCOMPLETE
```

nhưng object vẫn chứa:

```text
base_iv = 69,454
margin_of_safety = 38.1%
```



Tôi đồng ý giữ **fallback calculation để audit/debug**, nhưng không nên để consumer nhầm đó là valuation hợp lệ.

Nên schema:

```text
primary_valuation:
    status = MODEL_INCOMPLETE
    base_iv = null

fallback_valuation:
    model = NORMALIZED_OWNER_EARNINGS_DCF
    base_iv = 69,454
    usage = DIAGNOSTIC_ONLY
```

Tương tự:

```text
KSV
VOS
VJC
VHM
IDC
...
```

### Invariant

```text
if model_status != MODEL_VERIFIED:
    public_base_iv = null
    public_mos = null
```

Fallback IV chỉ xuất trong audit/debug.
