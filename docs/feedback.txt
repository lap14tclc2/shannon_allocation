# P1 mới: leverage penalty vẫn phạt công ty leverage khỏe

SCS là ví dụ rõ nhất.

Machine payload:

```text
net debt / EBITDA = 0.54x
debt payback       = 0.7 năm
```

đây là leverage rất nhẹ, nhưng engine vẫn:

```text
leverage_penalty_pct = +3
```



Tôi parse toàn 68 mã và tìm được **16 trường hợp** tương tự, trong đó cả hai metric đều <2 nhưng vẫn bị +3, ví dụ:

```text
AST   0.33x / 0.4y → +3
ACV   1.05x / 1.1y → +3
DHG   0.85x / 0.7y → +3
GAS   1.20x / 1.5y → +3
GMD   1.59x / 1.5y → +3
SCS   0.54x / 0.7y → +3
VGI   1.35x / 1.2y → +3
```

Nguyên nhân khớp với code vừa review: sau khi các threshold `>=2` không match, `_leverage_penalty()` vẫn làm:

```python
if net_debt > 0:
    return 3
```

Nó đang hiểu:

> positive net debt = thiếu leverage evidence

trong khi ở SCS **evidence đã có và rất khỏe**.

Phải đổi thành:

```python
if metrics_available:
    if ND_EBITDA >= 6 or payback >= 10:
        return 10
    if ND_EBITDA >= 4 or payback >= 5:
        return 6
    if ND_EBITDA >= 2 or payback >= 2:
        return 3
    return 0

if net_debt > 0 and metrics_unavailable:
    return 3
```

Đây là P1 correctness, không phải cosmetic.

# P1 quan trọng hơn: `unknown dilution` đang biến thành `0 dilution`

FRT hiện được tách dữ liệu đúng:

```text
raw share change           = 115.6%
non-economic explained      = 26.8%
confirmed economic dilution = null
unexplained share change    = 88.8%
classification              = UNEXPLAINED_SHARE_CHANGE
```



Đây là rất tốt.

Nhưng sau đó quality scorer lại cho:

```text
capital_allocation_score = 15/15
economic_dilution_5y_pct = 0
```

và capital allocation pillar còn ghi:

```text
status = GOOD
```

trong khi 88.8% share increase vẫn chưa giải thích được. 

Đây là lỗi **unknown → zero**.

Semantics phải là:

```text
confirmed dilution = null
```

không phải:

```text
confirmed dilution = 0
```

`null` nghĩa là:

> chưa biết.

`0` nghĩa là:

> đã xác nhận không có economic dilution.

Hai thứ hoàn toàn khác nhau.

### Tôi đề xuất invariant

```python
if classification == UNEXPLAINED_SHARE_CHANGE:
    confirmed_economic_dilution = None

    # no hard reject
    # no proven-dilution penalty
    confidence = LOW

    capital_allocation_score = min(
        capital_allocation_score,
        10,
    )
```

Không nên hard-reject FRT chỉ vì thiếu evidence, nhưng cũng **không nên award 15/15** khi 88.8% biến động số cổ phiếu chưa giải thích.

Đây là cách cân bằng đúng nhất.
