# Nhưng còn 3 lỗi quan trọng

### P0 — `LOW_QUALITY` vẫn có thể `ATTRACTIVE`

Đây chính là nguyên nhân FRT trong audit gần nhất quay lại `ATTRACTIVE`.

Trong `margin_of_safety.py` hiện logic là:

```python
if high_quality_and_satisfied:
    HIGH_CONVICTION_VALUE
elif satisfied:
    ATTRACTIVE
elif ...
elif quality_tier == LOW_QUALITY:
    AVOID_QUALITY
```

Tức nếu:

```text
quality = LOW_QUALITY
MOS = 48%
required MOS = 35%
```

thì nó vào:

```text
elif satisfied:
    ATTRACTIVE
```

trước khi tới `LOW_QUALITY`.

Vì vậy claim trong TASK-067:

> verdict quality gate already fixed

**chưa hoàn toàn đúng**.

Nên sửa thành invariant:

```python
if quality_tier == QualityTier.LOW_QUALITY:
    verdict = "AVOID_QUALITY"
elif hard_rejects:
    ...
elif satisfied:
    ...
```

hoặc tốt hơn tách:

```text
valuation_status = ATTRACTIVE
quality_status   = LOW_QUALITY
final_status     = AVOID_QUALITY
```

**Tôi xem đây là P0.**

### P1 — leverage penalty vẫn sai về semantics

`MarginOfSafetyEngine` đang nhận:

```python
has_solvency_risk = len(quality_scorecard.hard_rejects) > 0
```

sau đó:

```python
leverage_pen = (
    10 if has_solvency_risk
    else 5 if CAPITAL_INTENSIVE
    else 0
)
```

Đây không phải leverage calculation.

Hệ quả:

```text
company debt payback 12 năm
→ có thể leverage penalty = 0

company debt khỏe 1.5 năm
nhưng CAPITAL_INTENSIVE
→ leverage penalty = +5
```

Nó giải thích đúng anomaly tôi thấy trong audit trước.

Nên truyền trực tiếp:

```text
net_debt
debt_payback_years
net_debt/EBITDA
sector-specific leverage metric
```

rồi tính penalty từ leverage thực.

### P1 — `economic_dilution` vẫn đang chứa unexplained share change

Trong `app/main.py` hiện vẫn:

```python
"share_dilution_5y_pct": share_dilution_5y,
"economic_dilution_5y_pct": share_dilution_5y,
```

Trong khi ngay phía trên code có thể classify:

```text
UNEXPLAINED_SHARE_CHANGE
```

Đây là contradiction.

Ví dụ FRT:

```text
raw share increase             115.6%
non-economic explained          26.8%
unexplained                     88.8%
confirmed economic events          0
```

nhưng object vẫn truyền:

```text
economic_dilution_5y_pct = 88.8
```

Sau đó `QualityScorer` dùng chính `true_dilution_5y_pct` này để giảm điểm capital allocation.

Hard reject đã được ngăn bởi classification, nhưng **quality score vẫn đang bị phạt như thể 88.8% economic dilution đã được chứng minh**.

Nên tách:

```text
raw_share_change_pct
non_economic_share_change_pct
unexplained_share_change_pct
confirmed_economic_dilution_pct
```

Với FRT hiện tại:

```text
confirmed_economic_dilution_pct = null
unexplained_share_change_pct    = 88.8
```

Không nên dùng 88.8 để chấm capital allocation như confirmed dilution.
